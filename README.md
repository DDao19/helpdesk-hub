# HelpDesk Hub

HelpDesk Hub is a help desk ticket management application designed to simulate real-world IT service desk workflows. The goal of this project is to build a professional, user-friendly platform that helps IT support teams manage and track support requests efficiently.

## Tech Stack

**Frontend**

- React
- TypeScript
- Vite
- Tailwind CSS v4
- Lucide React

**Planned Backend & Infrastructure**

- Node.js
- Express
- PostgreSQL
- Prisma
- AWS

## Current Features

- Initial homepage layout

## Planned Features

- Staff authentication and role-based access for Admins and Agents
- Ticket creation and management
- Ticket status tracking and updates
- Ticket assignment and prioritization
- Responsive design for desktop and mobile devices

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/helpdesk-hub.git
   ```

2. Navigate to the project directory:

   ```bash
   cd helpdesk-hub
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
